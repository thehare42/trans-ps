# trans-ps
translate sub eng while play ps5

เว็บแอปไฟล์เดียว (`index.html`) ใช้กล้องมือถือส่องซับภาษาอังกฤษบนจอทีวี → อ่านด้วย OCR (Tesseract.js ในเครื่อง) → แปลไทยด้วย Google Translate → แสดงคำแปลทับตรงตำแหน่งซับ

## เปิดใช้งานบนมือถือ
เบราว์เซอร์จะยอมให้ใช้กล้องเฉพาะหน้าเว็บที่เป็น **https** จึงต้องโฮสต์ไฟล์นี้ก่อน วิธีง่ายสุดคือ GitHub Pages:

1. push repo นี้ขึ้น GitHub
2. Settings → Pages → Source: `Deploy from a branch` → branch `main` / `(root)` → Save
3. รอ 1–2 นาที แล้วเปิด `https://<username>.github.io/trans-ps/` บนมือถือ (Chrome บน Android หรือ Safari บน iPhone)

ทดสอบบน PC ก่อนได้ด้วยเว็บแคม: `python -m http.server 8000` แล้วเปิด `http://localhost:8000`

## วิธีใช้
1. วางมือถือบนขาตั้ง/ที่วางให้ **นิ่ง** เล็งตรงกับจอ ไม่เฉียง ไม่มีแสงไฟสะท้อนจอ
2. กด **เปิดกล้อง** → ถ้ามีแถบซูมใน "ตั้งค่า" ให้ซูมให้ซับใหญ่ขึ้น
3. กด **ลากกรอบซับ** แล้วลากนิ้วครอบเฉพาะบรรทัดซับ (ยิ่งแคบยิ่งเร็วและแม่น)
4. เปิด **ตั้งค่า** ดูภาพตัวอย่าง ปรับ "ความสว่างขั้นต่ำ" จนเห็นตัวอักษรสีดำชัดบนพื้นขาว และฉากหลังหายไปมากที่สุด
5. เล่นเกมได้เลย แอปจะแปลอัตโนมัติทุกครั้งที่ซับเปลี่ยน กด **แปลเดี๋ยวนี้** เพื่อบังคับอ่านใหม่ / **ประวัติ** เพื่อย้อนดูบรรทัดที่หลุดไป

## การแสดงคำแปล
- คำแปลไทยขึ้น **ทับตรงกรอบซับ** ในภาพกล้อง → วางมือถือใต้จอทีวีให้ตรงกับบรรทัดซับ ตาจะขยับแค่นิดเดียว
- **ซ่อนภาพกล้อง**: จอดำ เหลือแต่คำแปลตรงตำแหน่งซับ (ประหยัดแบต อ่านง่ายขึ้น)
- **ซ่อนปุ่ม**: ซ่อนแถบบน/ล่างทั้งหมด แตะจอเพื่อเรียกกลับ
- ตั้งค่า → ขนาดตัวอักษร, แสดงภาษาอังกฤษที่อ่านได้ใต้คำแปล (ไว้เช็กว่า OCR อ่านถูกไหม)

## การแปล
- แก้คำที่ OCR อ่านผิดบ่อยก่อนแปล เช่น `l'm` → `I'm`, `c0me` → `come`, `l` เดี่ยว → `I`
- ชื่อผู้พูดแบบ `KRATOS: ...` คงชื่อไว้เป็นภาษาอังกฤษ แปลเฉพาะบทพูด
- ประโยคที่ถูกแบ่งเป็น 2 ซับ (ซับแรกไม่จบด้วย . ! ? และซับถัดไปขึ้นต้นตัวเล็ก) จะถูกต่อกันแล้วแปลรวม ปิดได้ในตั้งค่า

## เคล็ดลับ
- ในเกม เปิดตัวเลือก Subtitle size ใหญ่สุด และ Subtitle background (พื้นหลังซับ) ถ้ามี → แม่นขึ้นมาก
- ซับจะเปลี่ยนแล้วแปลภายในราว 0.5–1.5 วินาที ขึ้นกับความเร็วมือถือ
- ถ้าแปลซ้ำ/กระพริบบ่อย ให้ลดความไว (เลขมากขึ้น); ถ้าซับเปลี่ยนแล้วไม่แปล ให้เพิ่มความไว (เลขน้อยลง)
